# 참고: 타 팀 림버스 TRPG VTT 방송 분석 (2026-11-21)

치지직 방송 녹화("[림버스 TRPG] 모지리 3명과 정상인 1명의 폭풍을 부르는 뒷골목 대작전", 6시간 40분, 1080p60, 23.4GB)를 프레임 단위로 훑은 기록. 방송에 쓰인 VTT는 **"LIMBUS PLAY"** 로고의 타 팀 웹 VTT이며, 룰(d6·7죄악 능력치·격자 이동)은 우리와 다르다. **UI 배치·연출 흐름의 참고 자료**로만 쓴다. 영상과 프레임(`video-frames/`)은 저장소에 올리지 않는다(gitignore).

추출 방법: ffmpeg 9로 1분마다 1장(seek 방식, 400장) → 접촉 시트로 구간 파악 → 핵심 장면 원본 해상도 + 판정·공격·전투 종료 구간 1초/2초 간격. 스크립트는 세션 스크래치패드(`vid.py`, `tile.py`), 필요하면 다시 만든다.

## 화면 구성 (1920×1080 기준, 방송 캡처라 우측 ~250px는 채팅 오버레이)
- **공통 하단 바**: 가운데 3개 모드 탭 `전투 / 스탠딩 / 철도`(아이콘+글자, 현재 탭 금색 테두리). 오른쪽 `채팅(안 읽음 배지) · 시트 · ●5명(접속) · 마스터 모드`. 왼쪽 로고. 그 위에 붉은 가죽 띠 장식.
- **스탠딩 모드**: 상단 좌측 PC 초상 4개 + 우측 NPC 초상(현재 화자 금색 테두리), 좌상단 라운드/장면 번호 패널, 배경 위에 스탠딩 2~4명(화자 외 어둡게), 하단 이름표(`해결사 바나`처럼 직업/소속 + 이름 꼬리표), 대사 띠(판정 결과도 같은 자리에 `나태 판정·64 완전한 성공`으로 남음). 그 아래 입력줄: `인물 셀렉트 | 표정 셀렉트 | 대사 입력 | 꾸미기 | 전송 | 등장 | 퇴장`.
- **판정 팝업("7죄악 판정")**: 인물 셀렉트+스트레스, 주사위 표시(1d6/2d6), 7죄악 아이콘 7개(전문 속성은 `전문 2d6` 배지), 체크 옵션 `분발(주사위 +1·스트레스 +2)`, `유리한 속성(결과 +1)`, `도움` 셀렉트, 버튼 `닫기 / 탐식 판정·1d6`.
- **판정 컷인**(약 3초): 화면 어둡게 → 좌측 세로 초상 카드(이름, 식별·주요 행동 꼬리표) → 가운데 죄악 아이콘+이름 → 주사위 눈이 큰 타일로 등장(대각선 주황 띠 배경) → 우측에 큰 결과 문구 `애매한 성공`. 끝나면 장면으로 복귀하며 대사 띠에 결과 요약.
- **전투 모드**: 좌상단 `ROUND n / TURN k/m` + 소모 자원(♥·⚔ 카운터). 좌측 세로 **순서 목록**(초상 원형+속도 숫자, 현재 턴 강조). 가운데 격자 맵(유닛 토큰 = 원형 초상+속도 배지, 아군/적 테두리 색). 상단 중앙 `OOO의 차례 · 선택 중 · 기다리는 중…`. 우상단 **유닛 패널**(이름, HP 바 `15/30`, 부상 단계 `경상◇◇◇ 중상◇◇◇ 치명상◇◇`, 상태 아이콘+수치, 스트레스/신속/속박, `시트` 버튼). 하단 중앙 **행동 패널**(현재 유닛 ♥·스트레스·남은 이동 `1/6`, `전력 이동 / 기타 행동`), **스킬 바** 8칸(아이콘 위 이름 탭, 아래 `근접 1칸`·`원거리 2칸` 사거리 꼬리표, 쓸 수 없는 건 회색), 그 아래 **파티 카드** 4장(초상·HP·속도). 우하단 큰 원형 `WAIT 처리 중 / END 턴 종료` 버튼. 우상단 아이콘 4개(도움말·음악·되돌리기·다시·저장).
- **합/공격 처리 패널**(우측): `공격 [6][1] 완전한 성공 6 / 방어 [4][3] 애매한 성공 4` → 붉은 띠 `공격 우세 — 적중` → 보호·저항 선택(`받을 피해: 경상 3칸`, 감소 방식 셀렉트, 서사 메모, `결과 미리보기`, `저항 / 저항 안 함`). 수비측은 `반격 (확정 적중) / 반격 안 함`.
- **범위 공격 선언 패널**: 대상 수, 모양(`근접 · 전방 사각 폭3×길이2`), 적중 시 효과 요약, 후보 이름, `공격 판정 전 선언: 분발·도움` 체크. 맵에는 붉은 격자 범위 + 말풍선 `자기 칸이 아닌 방향을 고르세요`.
- **공격 컷인**(약 3초): 어두운 배경에 공격자(좌)·대상(우) 전신 일러스트, 좌상단 스킬 이름 리본 + 육각 주사위 눈, 우상단 상대 `방어` 리본, 사선 섬광 → `적중` 큰 글자 + 대상 위 피해 수치(`경상 3`). 아래 `GM 알림` 한 줄(규칙 근거).
- **GM 콘솔**(우측 서랍, 탭 `진행 / 무대 / 전투 / 시트`): 전투 탭은 고른 유닛의 상태 수치 입력 격자, 스트레스/E.G.O 단계/뒤틀림 단계, 좌표 X/Y, `전체 회복 / 잠금까지 초기화 / 전투 불능으로`, 이니셔티브 최종값, 순서 앞뒤 이동, 내성치, `키워드 정산(화상·출혈)`. 시트 탭은 캐릭터 전체 목록에서 스트레스·E.G.O·뒤틀림을 한 줄씩 편집하고 `목소리 판정 / 체력 회복` 버튼.
- **채팅 서랍**(좌측, 탭 `채팅 / 주사위 / 팝업 로그 / 내 기록 지우기 / 전체 지우기`): 주사위 로그는 카드 하나에 `공격 [5][3]=5 비대응·굴림 없음`, `라나드 자유 굴림 2d6 [5][3] 합 8·최고 5`, `잡졸일 1→김에덴 석궁 사격 공격 [4][2][6]=6 방어 [2][4][1]=4 → 공격 우세—적중`, `라운드 6 이니셔티브` 표(이름·주사위·→ 6 빠름/4 중간/1 느림). 맨 아래 안내 "공격·대응 결과는 대응이 확정되어 공개된 뒤에 올라와요".
- **상태(키워드) 편집 팝업**: 항목마다 `아이콘 글자 | 이름 | 이로운/해로운 셀렉트 | 삭제`, 설명 텍스트, `자동화 설정`(횟수형·적용 조건 요약). 아래 입력줄 `+추가`.
- **캐릭터 시트**(모달, 좌 1/3 일러스트 + 우 2/3 탭): 왼쪽 세로 메뉴 `캐릭터 설정 / 일러스트 / 판정 / 스탠딩 / 전투 자세`, 하단 `스테이터스`(체력·거리·최대 체력·전문 속성 2개 `[2d6]`). 오른쪽 상단 큰 제목 `『한 줄 콘셉트』 + 이름 + 역할 배지(플레이어/적)`, `스트레스 n/10 · E.G.O 단계 · 뒤틀림 단계` 바, 탭 `요약 / 스킬 / E.G.O / 정신력`. 편집 모드는 "글·숫자·그림을 눌러 바로 바꿔요, 저장은 자동" 안내 + `✓ 편집 끝`. E.G.O 탭: 초상 + 이름 + 한 줄 + `연출 / 기본 효과 / 지속 시간` 블록.
- **목소리 판정 → 변화 연출**: 작은 컷인(초상+`목소리 판정`+주사위) → 전체 화면 `뒤틀림` 붉은 글자 → 초상 확대 → `1단계 ○○○` 단계명 카드. E.G.O는 `E.G.O 개화` → 초상 → `TETH E.G.O` 갑옷 카드. 전체 각성은 상하 `FULL AWAKENING` 띠 + 초상.
- **분위기 장치**: 엔딩 송 카세트 오버레이(좌상단, 곡명·`엔딩 송`), 후원 알림, 전투 중 BGM 아이콘.

## 무대(GM) 패널 세부 (키 프레임 4:12:36, 2:06:20)
스탠딩 모드에서 GM 콘솔 `무대` 탭은 오른쪽 위에 떠 있는 패널 하나에 다 들어 있다.
- **장면 전환**: 배경 썸네일 띠(`배경 없음`, 1, 2, 3, 34… 현재 배경에 `현재` 빨간 배지) → 방식 버튼 `페이드 / 암전 / 섬광 / 즉시` → `전환`(배경을 안 고르면 `배경을 먼저 고르세요` 붉은 비활성) · `배경 관리`.
- **제목 카드**: `제1장 · 녹슨 사슬` 제목 + 부제 입력, `표시` 버튼(화면 가운데 제목 카드 연출).
- **컷인**: 인물 셀렉트 + `E.G.O / 뒤틀림 / 보스 등장` 버튼(위 연출을 GM이 수동으로도 쏜다).
- **캐릭터 동작**: 인물 셀렉트 + `놀람 떨림 끄덕 고개 젓기 움찔 들이밀기 한숨 다가서기 물러서기 쓰러짐 돌아서기 제자리` 12개 — 스탠딩 하나에 짧은 트윈을 거는 버튼.
- **BGM**: `고요한 밤 긴장 불안 긴박 예수 수수께끼 U사 스토리 전투 끄기`(재생 중 표시). **효과음**: `쾅 타격 베기 휘익 노크 문 삐걱 발소리 심장박동 잡음 첫소리`. **대기** `1초 2초 3초`(연출 사이 간격). `음원 추가 mp3·ogg 직접 주소(예: GitHub 저장소에 올린 파일)`.
- 입력줄 오른쪽 버튼이 GM이면 `꾸미기 전송 퇴장 판정`, 플레이어면 `꾸미기 전송 등장/퇴장`.
- 철도 모드 하단에는 `자막 제목 / 자막 내용` 입력(자막 띠), 입장 승인 요청 알림 토스트("멤버 관리에서 확인하세요").

## 캐릭터 시트 세부 (1:06, 2:22, 4:12)
- **요약 탭**: 위에 원형 게이지 2개(`E.G.O` 금색 / `뒤틀림` 붉은색, 단계 숫자), 스킬 아이콘 줄(육각 죄악 아이콘 + 번호 + 이름), 아래 `7죄악 판정` 행(아이콘 7개, 전문 속성은 밝게).

- **E.G.O 탭**: 하위 탭 `E.G.O / 뒤틀림`. 초상 + 이름 + 한 줄 설명, `연출 / 효과(▶ 항목들) / 기본 효과 / 지속 시간` 블록, 맨 아래 `[E.G.O 전용 스킬]` 링크. 편집 모드엔 `영상 소리 사용(기본 효과음 대신)` 체크.
- **그림 초점 맞추기 팝업**(일러스트 메뉴): 탭 `E.G.O 그림 / 스탠딩(거울 개화 첫 장면)`, 큰 미리보기에서 초점을 누르거나 끌고 `확대 1.00배` 슬라이더, 오른쪽에 용도별 자동 크롭 미리보기 3개(`거울 개화 틈` 가로, `발현 띠` 가로 띠, `카드` 세로), `기본값(가운데 위)`, `컷인 미리보기`, `닫기`. — 그림 한 장으로 초상·띠·카드를 다 만드는 방식.
- **전투 자세 팝업**: 그림 규격 안내(캔버스 세로 1500px 고정·가로 1000px 이상, 투명 PNG/WebP, 오른쪽 보게 그리기, 발끝 1440px 선·정수리 150px 선, 여섯 자세 같은 캔버스) + 자세 6칸(`대기 돌진 공격 방어 피격 …`, 각 칸에 붉은 실루엣 가이드와 `비어 있음`). 스탠딩이 없으면 "스탠딩 이미지가 없어요, 시트에서 먼저 넣어 주세요".
- 새 시트: `수감자 기록 No. 18` 양식(이름/나이/직업·소속/한 줄 콘셉트), 안내 "직업/소속은 스탠딩 이름표 위에 표시됩니다", 스테이터스 기본 체력 30, 전문 속성은 "책 아이콘에서 선택". 역할 배지 `플레이어 / 적`, NPC 시트는 상단 검색 꼬리표(`조직원·척후 / 나태 / 질투`).
