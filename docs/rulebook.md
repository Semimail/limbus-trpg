# 림버스 TRPG 룰북 초안 (v0.1)

> 결정된 것은 본문에, 아직 정하지 않은 것은 `[미결]`로 표시한다.
> 수치는 캠페인 설정에서 조정 가능하며, 본문의 값은 기본값이다.

## 1. 핵심 판정: 코인

- 모든 판정은 코인을 던져 처리한다. 앞면 확률 = 50% + 정신력%.
- 정신력 범위는 -45 ~ +45. 따라서 앞면 확률은 5% ~ 95%.
- 정신력은 세션 안에서 계속 이어진다. 전투가 끝나도 초기화하지 않으며 GM이 서사 사유로 조정할 수 있다.
- 기본 변동: 합 승리 +10, 합 패배 -10. 특기나 기믹으로 이 규칙을 바꿀 수 있다.

## 2. 캐릭터

### 능력치 (죄악 7종)
분노, 색욕, 나태, 탐식, 우울, 오만, 질투. 각 1~5.
- 생성 시 총 14포인트 배분, 5는 하나까지. `[미결: 테스트 후 조정]`
- 비전투 판정의 코인 수가 된다.

### 특기
- 자유 서술 문구. 생성 시 2개. 상황에 맞으면 비전투 판정에 코인 +1.
- 전투용 효과를 가진 특기는 "조건 + 행동 + 대상 + 수치"로 구조화해 저장하고 사이트가 자동 실행한다.
  예) 매 라운드 시작 → 호흡 1/1 → 자신.
- 자연어로 쓰면 AI가 구조화 초안을 만들고 GM이 승인한다. 구조화가 안 되는 특기는 서사용으로 두고 GM이 수동 적용한다.

### 스킬
- 공격 스킬 3개(티어 1/2/3, 덱 비율 3:2:1) + 방어 스킬 1개(가드/회피/반격) + E.G.O.
- 스킬 = 기본 위력, 코인 위력, 코인 수(최대 14), 피해 유형(참격/관통/타격), 죄악 속성, 부가 효과.
- 플레이어가 자유 창작하고, 포인트 공식으로 상한을 검사하며, GM이 승인한다. `[미결: 포인트 공식]`
- 포인트 상한은 등급과 레벨에 따라 오른다.

### 빛 (메타 재화)
- 세션 시작 시 3개, 세션 종료 시 초기화. GM이 RP 보상으로 추가 지급. `[미결: 수량]`
- 용도: 판정 재굴림, 뽑은 스킬 교체, 특기 추가 발동.

### 배경
서사용 텍스트. 규칙상 효과는 후속 구현.

### 아이템
자유 텍스트 인벤토리. 1차에서 수치 효과 없음.

## 3. 성장

### 등급과 레벨
7등급: 뜬소문 → 도시괴담 → 도시전설 → 도시의 악몽 → 도시의 재앙 → 별 → 불순물.
등급당 7레벨, 총 49레벨 (설정값).
- 레벨업: 체력 증가, 스킬 포인트 상한 증가.
- 등급 상승: 특기 1개 추가, 패시브 해금 기회.
- 경험치는 GM이 세션 종료 후 반영한다.
- 상한 참고 수치: 체력 6자리, 위력 3자리, 코인 14개가 최종 등급 수준.

### 동기화 (1~4단계)
- 각 단계: 스킬 1개 강화(위력/코인/효과 중 하나) + 명칭과 외형 변경(서사 이벤트).
- 3단계: 속도 다이스 2개 해금. 4단계: 고유 패시브 해금.
- 발동은 GM이 서사로 열고, 시스템은 최소 레벨만 검사한다.

### 패시브
공명이나 보유 조건 대신 "특수 조건"으로 발동. 후속 해금.

### E.G.O
- 사용 비용: 정신력 소모 + 전투당 횟수 제한 + 침식도.
- 침식도: E.G.O 사용마다 상승, 일정치를 넘으면 침식 판정. 세션 종료 시 초기화.
- 침식(폭주): 코인을 던져 뒷면이면 그 라운드 GM이 조종.

## 4. 전투

### 라운드 흐름
1. 속도 다이스: 모든 참가자가 속도 범위 안에서 다이스를 굴린다 (기본 1개, 동기화 3단계에서 2개). 적은 별도 설정.
2. 스킬 선택: 플레이어는 덱에서 뽑힌 스킬 중 선택. 적은 덱 자동 뽑기 + 대상 랜덤, GM이 수동 덮어쓰기 가능.
3. 합 가로채기: 속도가 더 빠른 쪽은 적 스킬의 대상을 자신으로 바꿀 수 있다.
4. 속도 순으로 합 또는 일방 공격 처리.
5. 라운드 종료: 흐트러짐 만료 처리.

### 합
- 양쪽이 남은 코인을 전부 던져 총 위력을 비교한다. 패자는 코인 1개를 잃는다. 동률이면 다시 던진다.
- 한쪽 코인이 0이 되면 승자가 남은 코인으로 일방 공격한다. 각 코인의 누적 위력만큼 피해.
- 방어 스킬이 합에서 이기면 피해 없이 종료. 반격은 후속 구현.
- 합 승리 +10 / 패배 -10 정신력.

### 피해
- 피해 = 코인 누적 위력 × 저항 × 흐트러짐(2배) × 치명타(1.5배). 소수점 버림.
- 저항(피해 유형 × 죄악 속성)은 캠페인 설정으로 끈다/적만/전체. 기본 끔.

### 치명타와 호흡
- 호흡 N을 가진 쪽이 앞면 적중 시 (N × 5%) 확률로 치명타.
- 치명타 시 호흡은 절반. 치명타 피해는 1.5배 고정이며 플레이어가 수정할 수 없다.

### 흐트러짐
- 체력이 최대치의 50%, 30% 선을 넘어 내려가면 흐트러짐. 각 구간은 전투 중 1회.
- 흐트러진 동안 행동 불가, 받는 피해 2배. 다음 라운드 종료 시 해제.
- 추가 기믹은 후속.

### 전투불능
체력 0은 전투불능. 사망 여부는 전투 후 GM이 서사로 결정한다. 자동 회복은 없다.

### 상태이상 (숫자 하나, 발동 후 절반)
모든 상태는 숫자 N 하나로 관리한다. 같은 상태를 또 받으면 더하고(상한 99, 충전은 20), 발동하면 절반(내림)으로 줄어든다. 1은 발동 후 사라진다.

| 상태 | 발동 시점 | 효과 |
|---|---|---|
| 화상 | 라운드 종료 | N 피해 |
| 출혈 | 보유자가 공격 코인을 굴릴 때마다 (합 코인 제외) | N 피해. 3코인이면 N, N/2, N/4 |
| 파열 | 보유자가 피격당한 스킬 1회 종료 후 | N 추가 피해 |
| 침잠 | 보유자가 피격당한 스킬 1회 종료 후 | 정신력 -N |
| 진동 | 흐트러진 상태로 피격 | 흐트러짐 피해 배율 2배 + N x 10% `[확인 요청]` |
| 호흡 | 앞면 적중 | N x 5% 확률로 치명타(1.5배). 치명타가 나면 절반 |
| 충전 | 자동 발동 없음 | 스킬 효과가 "충전 X 소모"로 사용. 라운드 종료에도 줄지 않음 |

## 5. 비전투 판정
- 능력치 + 보너스 코인(특기, 빛)만큼 던져 앞면 수 ≥ 난이도(1~5)면 성공.
- 대립 판정(PC vs NPC, PC vs PC): 양쪽이 던져 앞면 수 비교, 동률은 방어 측 승리.
- 자유 주사위 명령(/r 2d6 등)도 지원.

## 6. 적 도감
- GM은 전체 열람.
- 플레이어는 자기 캐릭터가 마주친 적만 보이고, 그 적이 실제로 사용한 스킬과 발동한 기믹만 공개. 미공개는 ???.
- GM이 수동 공개 가능. 공개 여부는 캐릭터 단위로 기록.
- 도감은 세션 로그와 달리 삭제하지 않는다.
