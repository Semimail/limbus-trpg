# 림버스 TRPG 룰북 (v0.2)

> 림버스 컴퍼니 세계관을 빌린 2차 창작 TRPG의 규칙서입니다. 사이트가 계산을 대신하므로 플레이어는 선택에 집중하면 됩니다.
> 본문의 수치는 기본값이며 GM이 캠페인 룰 설정에서 바꿀 수 있습니다. 아직 정하지 않은 항목은 `[미결]`로 표시했습니다.

## 1. 한눈에 보기

- 모든 판정은 **코인**으로 합니다. 앞면 확률은 50% + **정신력**%.
- 전투는 라운드마다 **속도**를 굴리고, **손패** 3장 중 스킬을 골라, 서로를 노리면 **합**을 겨룹니다.
- 체력이 50%, 30% 선을 넘어 떨어지면 **흐트러짐**. 행동 불가, 피해 2배.
- 상태이상은 숫자 하나로 관리하고, 발동하면 절반이 됩니다.
- **E.G.O**는 정신력을 지불해 쓰며 **침식** 위험이 있습니다. **빛**은 세션당 3개의 메타 재화입니다.
- 캐릭터는 7개 **죄악** 능력치, **특기** 2개, 공격 스킬 3개와 방어 스킬 1개로 시작합니다.

## 2. 핵심 판정: 코인

| 항목 | 규칙 |
|---|---|
| 앞면 확률 | 50% + 정신력%. 정신력 +45면 95%, -45면 5% |
| 스킬 위력 | 기본 위력 + 앞면 코인 수 × 코인 위력 |
| 비전투 판정 | 능력치 수만큼 코인을 던져 앞면 수 ≥ 난이도(1~5)면 성공 |
| 대립 판정 | 양쪽이 던져 앞면 수를 비교. 동률은 방어 측 승리 |
| 정신력 범위 | -45 ~ +45. 세션 안에서 이어지며 전투가 끝나도 초기화되지 않음 |
| 정신력 변동 | 합 승리 +10, 합 패배 -10. 특기나 기믹으로 바꿀 수 있음 |

## 3. 캐릭터 생성

### 생성 순서
1. 이름, 초상화, 배경(출신, 소속, 해결사가 된 계기)을 정한다. 배경은 서사용이며 규칙 효과는 `[미결]`.
2. 죄악 7종에 총 14포인트를 나눈다. 각 1~5, 5는 하나까지.
3. 특기 2개를 문장으로 적는다.
4. 공격 스킬 3개(스킬1·2·3)와 방어 스킬 1개를 만든다. 기대 위력 상한을 넘기면 저장되지 않는다.
5. GM이 승인하면 캠페인에 참가한다. 플레이어 한 명이 기본 2명까지 운용할 수 있다.

### 능력치 (죄악 7종)

| 죄악 | 뜻 | 비전투 판정 예 |
|---|---|---|
| 분노 | 힘과 위협 | 완력, 위압, 돌파 |
| 색욕 | 매력과 유혹 | 매혹, 감정 설득, 거래 |
| 나태 | 인내와 침착 | 버티기, 평정, 잠복 |
| 탐식 | 생명력과 탐색 | 체력, 추적, 수색 |
| 우울 | 감수성과 통찰 | 공감, 직감, 분위기 읽기 |
| 오만 | 지성과 설득 | 지식, 논리, 명령 |
| 질투 | 민첩과 눈치 | 손재주, 은신, 반사 |

능력치는 비전투 판정의 코인 수가 됩니다. 스킬의 죄악 속성과 능력치는 같은 이름을 쓰지만 서로 다른 것입니다.

### 특기
- 캐릭터 고유의 문장. 생성 시 2개, 등급이 오를 때 1개씩 추가.
- 상황에 맞으면 비전투 판정에 코인 +1 (`/coin 분노 2 +1`).
- 규칙 형태로 적으면 전투에서 자동 실행된다. 시트에서 "자동" 또는 "수동(GM)"으로 해석 결과가 바로 보인다. 형태는 9장 참고.

### 스킬
- 공격 스킬 3개 + 방어 스킬 1개. 각 스킬은 기본 위력, 코인 위력, 코인 수, 피해 유형(참격/관통/타격), 죄악 속성, 부가 효과 문장을 가진다.
- 공격 스킬은 티어에 따라 덱에 3장(스킬1), 2장(스킬2), 1장(스킬3) 들어간다. 티어가 높을수록 세고 적게 나온다.
- 방어 스킬(가드/회피/반격)은 덱 밖에 있어 항상 고를 수 있다.
- **기대 위력** = 기본 위력 + 코인 수 × 코인 위력 × 0.5. 레벨별 상한은 부록 표 참고. 1레벨 상한은 스킬1 5, 스킬2 7, 스킬3 10, 방어 7.
- 코인 위력은 음수도 가능하다. 앞면이 나올수록 약해지는 스킬이 된다.

### E.G.O
- GM이 서사로 열어주면 시트의 E.G.O 항목에 추가한다. 정신력 소모(기본 20), 침식도 증가(기본 10), 전투당 횟수(기본 1)를 정한다.
- 덱 밖에 있어 항상 고를 수 있다. 발현 시 정신력을 즉시 지불하고 선택이 확정된다.
- 지불 후 정신력이 0 미만이면 코인을 던져 뒷면이면 **침식**. 침식도가 100이면 무조건 침식.

### 빛
- 기본 3개. GM이 좋은 연기와 서사 보상으로 추가한다.
- 전투 중 빛 1로 손패를 전부 교체한다. 비전투 판정에 `빛`을 붙이면 코인 +1.

## 4. 성장

### 등급과 레벨
7등급 × 7레벨 = 49레벨. 경험치는 GM이 세션 뒤에 반영한다.

| 등급 | 레벨 | 등급 상승 시 |
|---|---|---|
| 뜬소문 | 1~7 | 시작 |
| 도시괴담 | 8~14 | 특기 +1, 패시브 해금 기회 |
| 도시전설 | 15~21 | 특기 +1 |
| 도시의 악몽 | 22~28 | 특기 +1 |
| 도시의 재앙 | 29~35 | 특기 +1 |
| 별 | 36~42 | 특기 +1 |
| 불순물 | 43~49 | 특기 +1 |

레벨이 오르면 최대 체력, 스킬 기대 위력 상한, 코인 상한이 오른다. 수치는 부록 A.

### 동기화 (1~4단계)
- GM이 서사로 연다. 시스템은 최소 레벨만 검사한다. `[미결: 단계별 최소 레벨]`
- 각 단계: 스킬 1개의 위력·코인·효과 중 하나를 강화하고 명칭과 외형을 바꾼다.
- 3단계: 속도 다이스 2개. 4단계: 고유 패시브.

### 패시브
공명이나 보유 조건 대신 "특수 조건"으로 발동하는 상시 효과. 특기와 같은 문장 형태로 적는다. `[미결: 해금 조건]`

## 5. 전투

### 라운드 흐름
1. **속도**: 생존 유닛이 속도 범위 안에서 다이스를 굴린다(기본 1개, 동기화 3단계부터 2개). 흐트러진 유닛은 슬롯을 받지 않는다.
2. **손패**: 덱에서 3장이 되도록 뽑는다. 쓴 카드는 버린 패로 가고 덱이 비면 섞어 다시 쓴다.
3. **선택**: 플레이어는 슬롯마다 손패·방어·E.G.O 중 하나와 대상을 고른다. 적은 자동으로 고르고 의도(아이콘과 대상)가 보인다. 빛 1로 손패 교체.
4. **가로채기**: 내 속도가 상대 슬롯 속도 이상이면 다른 아군을 노리는 공격을 내 쪽으로 끌어와 합을 겨룬다.
5. **처리**: 속도 순으로 합 또는 일방 공격. 대상이 이미 쓰러졌으면 같은 편 생존자 중 무작위로 바뀐다.
6. **라운드 종료**: 화상 발동, 흐트러짐 해제, 침식 해제, 라운드 종료 효과.

### 합
- 서로를 노린 두 슬롯은 합을 겨룬다. 남은 코인을 전부 던져 총 위력을 비교하고, 진 쪽은 코인을 1개 잃는다. 동률은 다시 던진다.
- 한쪽 코인이 0이 되면 이긴 쪽이 남은 코인으로 일방 공격한다.
- 방어 스킬이 이기면 피해 없이 끝난다. 반격은 남은 코인으로 공격한다.
- 합 승리 +10, 패배 -10 정신력. 정신력이 없는 적은 변하지 않는다.

### 일방 공격과 피해
- 코인을 하나씩 던지며 그 시점의 누적 위력만큼 피해를 준다.
- 피해 = 누적 위력 × 저항 × 흐트러짐 배율 × 치명타 배율. 소수점 버림.
- 저항은 캠페인 설정에서 끔/적에게만/전체. 기본은 끔. 배율은 치명 2.0 / 취약 1.5 / 보통 1.0 / 견딤 0.75 / 내성 0.5 / 면역 0.

### 흐트러짐
- 체력이 최대치의 50%, 30% 선을 넘어 떨어지면 흐트러진다. 각 구간은 전투 중 1회.
- 흐트러진 동안 행동 불가, 받는 피해 2배(진동이 있으면 + 진동 × 10%). 다음 라운드가 끝나면 풀린다.

### 치명타
- 호흡 N을 가진 쪽이 앞면 적중 시 N × 5% 확률로 치명타. 피해 1.5배 고정.
- 치명타가 나면 호흡은 절반.

### 전투불능과 회복
- 체력 0은 전투불능. 사망 여부는 전투 후 GM이 서사로 정한다.
- 자동 회복은 없다. 전투가 끝나면 체력, 정신력, 빛, 침식도가 시트에 그대로 반영된다. 회복은 GM이 휴식 장면으로 처리한다.

## 6. 상태이상

모든 상태는 숫자 N 하나로 관리한다. 같은 상태를 또 받으면 더해지고(상한 99, 충전은 20), 발동하면 절반(내림)이 된다. 1은 발동 후 사라진다.

| 상태 | 발동 시점 | 효과 | 발동 후 |
|---|---|---|---|
| 화상 | 라운드 종료 | N 피해 | 절반 |
| 출혈 | 보유자가 공격 코인을 던질 때마다 | N 피해 (3코인이면 N, N/2, N/4) | 절반 |
| 파열 | 피격당한 스킬 1회 종료 후 | N 추가 피해 | 절반 |
| 침잠 | 피격당한 스킬 1회 종료 후 | 정신력 -N | 절반 |
| 진동 | 흐트러진 채 피격 | 흐트러짐 배율 2배 + N × 10% | 절반 |
| 호흡 | 앞면 적중 | N × 5% 확률로 치명타 | 치명타 시 절반 |
| 충전 | 없음 | 스킬이 "충전 N 소모"로 사용 | 소모한 만큼 |

출혈은 합에서 위력 비교용으로 던지는 코인에는 걸리지 않는다. 진동은 흐트러지지 않았으면 효과가 없다.

## 7. E.G.O와 침식

| 단계 | 내용 |
|---|---|
| 발현 | 행동 선택에서 E.G.O 카드를 고르면 즉시 정신력 지불, 침식도 증가, 횟수 소모. 선택 확정 |
| 침식 판정 | 지불 후 정신력이 0 미만이면 코인 1개. 뒷면이면 침식 |
| 강제 침식 | 침식도 100 이상이면 판정 없이 침식 |
| 침식 상태 | 그 라운드 조종 불가. 손패에서 무작위 스킬로 아군·적 가리지 않고 무작위 대상 공격 |
| 해제 | 라운드가 끝나면 풀린다. 침식도는 남는다 |
| 침식도 관리 | 세션 사이에 GM이 서사(휴식, 사건)에 따라 내린다 `[미결: 자연 감소]` |

## 8. 비전투 판정과 채팅 명령

| 명령 | 뜻 |
|---|---|
| `/r 2d6+3` | 주사위 |
| `/coin 4 2` | 코인 4개, 난이도 2 |
| `/coin 분노 2` | 선택한 캐릭터의 분노 수치만큼 코인, 난이도 2 |
| `/coin 분노 2 +1` | 특기 보너스 코인 +1 |
| `/coin 오만 3 빛` | 빛 1을 써서 코인 +1 |
| `/vs 오만 상대이름 색욕` | 대립 판정. 상대는 캠페인 내 캐릭터 이름. 동률은 방어 측 승리 |

채팅 종류: 캐릭터 발언, 플레이어 발언, GM 서술, 시스템(굴림 결과), 귓속말. 이미지 전송 가능. GM은 메시지를 지울 수 있다.

## 9. 효과 문장 (자동 실행)

특기, 스킬 부가 효과, E.G.O 효과, 적 기믹은 같은 형태의 문장으로 적는다. 저장할 때 해석되어 전투에서 자동 실행된다.

`[트리거] [조건] [대상] [행동]` 순서. 여러 문장은 마침표나 줄바꿈으로 나눈다. "(전투당 1회)"를 붙이면 한 번만.

| 자리 | 쓸 수 있는 말 |
|---|---|
| 트리거 | 매 라운드 시작 시 / 라운드 종료 시 / 전투 시작 시 / 사용 시 / 앞면 적중 시 / 뒷면 시 / 적중 시 / 치명타 시 / 합 승리 시 / 합 패배 시 / 처치 시 / 흐트러질 때 / 피격 시 |
| 조건 | 충전 N 이상이면 / 정신력 N 이상이면 / 정신력 N 미만이면 / 체력 N% 미만이면 / 대상의 출혈 N 이상이면 (상태 이름은 7종 모두) |
| 대상 | 자신 / 대상 / 아군 전체 / 적 전체 / 전체 |
| 행동 | 화상 N 부여 (상태 7종) / 정신력 +N / 정신력 -N / 체력 N 회복 / 체력 N% 회복 / N 피해 / 코인 위력 +N / 기본 위력 +N / 충전 N 소모 |

트리거를 생략하면 스킬은 "적중 시", 특기는 "매 라운드 시작 시"로 본다. 대상을 생략하면 상태 부여와 피해는 "대상", 나머지는 "자신". 위력 보정과 충전 소모는 "사용 시"에만 적용된다.

예시
- 매 라운드 시작 시 자신에게 호흡 2 부여
- 앞면 적중 시 대상에게 출혈 3 부여
- 충전 5 이상이면 충전 5 소모하고 기본 위력 +10
- 합 승리 시 정신력 +5 (전투당 1회)
- 라운드 종료 시 아군 전체 체력 5 회복

해석되지 않은 문장은 "수동(GM)"으로 표시되고, GM이 전투 보드의 "조정"으로 직접 반영한다.

## 10. 세션 진행

- **사무소**: 로그인하면 바로 보이는 허브. 세션 입장, 의뢰 게시판, 내 캐릭터, 파티원, 기록 보관소, 적 도감.
- **장면**: 드라마 / 탐색 / 전투. 드라마·탐색 장면에는 배경 이미지와 토큰 보드. 전투 장면에는 전투 보드.
- **적 도감**: GM이 적을 등록한다. 플레이어는 마주친 적과 그 적이 실제로 쓴 스킬만 보고 나머지는 ???. GM이 기믹을 개별 공개할 수 있다.
- **내보내기와 리플레이**: GM이 세션을 JSON으로 저장한다. 채팅, 굴림, 장면, 전투 라운드별 상태가 들어간다. 로그인 없이 `/replay`에서 재생한다. 내보낸 뒤 세션을 삭제해 용량을 줄인다.
- **룰 설정**: 본 GM이 저항, 흐트러짐 구간과 배율, 치명타, 정신력 변동, 침식 기준, 성장 공식을 바꾼다. 새 전투부터 적용.

## 11. GM 가이드

### 적 설계
- 체력은 같은 등급 캐릭터의 1~2배, 보스는 3~5배를 기준으로 시작한다.
- 스킬은 2~4개. 티어 비율이 그대로 등장 빈도가 된다. 강한 스킬은 티어 3으로.
- 정신력이 없는 적(환상체)은 앞면 50% 고정이라 안정적이다. 정신력이 있는 적(인간형)은 합에서 밀리면 급격히 약해진다.
- 기믹은 효과 문장으로 적으면 자동 실행된다. 플레이어에게는 공개하기 전까지 ???로 보인다.

### 난이도 조절
- 플레이어가 뭉쳐서 한 적을 노리면 합이 한 번만 성립하고 나머지는 일방 공격이 된다. 적 수를 늘리면 체감 난이도가 크게 오른다.
- 흐트러짐 구간을 넘기는 한 방은 전투의 흐름을 바꾼다. 적의 티어 3 스킬 위력을 그 기준으로 맞춘다.

### 진행 요령
- 전투 보드의 "조정"으로 체력, 정신력, 상태를 언제든 고칠 수 있다. 수동 효과는 여기서 반영한다.
- 세션이 끝나면 내보내기 → 확인 → 세션 삭제 순서로 정리한다.
